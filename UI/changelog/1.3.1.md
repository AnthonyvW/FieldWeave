# What's Changed
---
This update comes with a lot of quality of life improvements for both area scans and tree core scans. For tree core scans the most notable improvement is the new option for automated image stitching along with automatically taking a single picture of the calibration slide before every tree core! It's currently a known issue that the automatic DPI calibration tends to fail, as such the singular image option was added as a backup. No more having to manually take an image of the calibration slide before hand! just set it once and then leave it there with the option checked and it'll do it every time going forward. 

As usual, if you come across any bugs while using FieldWeave, have feedback, or just want to request new features, please send them to <contact@FieldWeave.com> or open an issue on Github at <https://github.com/AnthonyvW/FieldWeave/issues/new>

# New Features & Improvements
---
- Added image stitching for tree core automation.
- Added option to take a single photo of a calibration slide for tree core imaging routines.
- Added option to image calibration slide before imaging all tree core samples.
- The load image feature can now convert tiffs into tiffs with pyramids vastly decreasing future loading times.
- The OS will no longer go to sleep when doing an imaging routine for both Windows and Debian based Linux distros.
- If the motion controller has issues, automations will now pause instead of continuing in a faulted state.
- Improved image loading speeds when using the load image feature in the measurement tab.
- The load image feature can now convert tiffs into tiffs with pyramids vastly decreasing future loading times.
- Multiple focus stacking routines can be ran concurrently for area scans, this can be found in the focus stacking advanced settings under "Concurrent Stacks".
- Area scans now state the time and date of when they'll be done.
- Time estimates are now more accurate for taking photos.
    - Per camera, per resolution time estimates are now saved and used in the automation time estimates.
    - Focus stacking now keeps track of time and provides a time estimate.
    - Automation now displays total estimated time including focus stacking.
    - Actual travel time is now taken into account. This will go into effect after an area scan is done.
- Camera calibration now gives feedback on whether or not a calibration is bad.
- Last used COM port is now saved.
- Last used camera is now saved.
    - These two changes combined allow two separate copies of FieldWeave to run on the same machine if it has sufficient resources.
- Can now disable individual axis
- Can now disable homing per axis
- Improved performance of logs tab.
- Logs tab auto scroll only applies when you're at the bottom of the logs now.

# Bugfixes
---
- Load Image in the measurements tab no longer consumes multiple gigabytes of ram when opening images with pyramids.
- Fixed race condition that occasionally appears when doing focus stacks in the tree core imaging routine causing the focus stack to fail.
- Fixed click to move failing on high resolution images.
- Fixed issue where switching away from a USB camera before it was ready caused an error.
- Fixed issue where navigation widget didn't grey out while homing.

# Known bugs
---
- Automatic DPI calibration fails if slide isn't perfectly straight.
- Automatic DPI calibration tends to fail when using high resolution imagery.
