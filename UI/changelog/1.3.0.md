# What's Changed
---
FieldWeave now has a changelog! It will display after every update, if you miss it and want to view it again, you can do so in the about page in the settings.

# New Features & Improvements
---
- Added patch number to versioning scheme
- Added patch notes pop up
- Added button to view patch notes in the about page in settings

# Bugfixes
---
- Version field in config files now successfully migrates and is saved
- Fixed the post processing manager creating a redundant config
- While developing it will no longer warn about failing to update.
- Toasts no longer throw errors if you close the program while one is active.
